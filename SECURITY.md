# Política de seguridad

Si encuentras una vulnerabilidad, no abras un issue público. Escribe al Área de Sistemas del EDUMAS:

- info@edumas.gov.co, asunto "Seguridad – Carnet digital"

Incluye la descripción, los pasos para reproducirla y el impacto. No hagas pruebas que modifiquen o borren datos reales en el proyecto de producción `carnet-edumas`; usa el emulador de Firebase (`firebase emulators:start`).
